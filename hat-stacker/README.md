# Hat Stacker

A small canvas game starring the VS Code pet, Buddy. Catch every falling hat,
keep the growing stack upright, and counter-steer as the tower gets heavier.

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run check
```

## Controls

- Move with `A` / `D` or the left / right arrow keys.
- Drag or tap across the playfield on pointer and touch devices.
- Pause with `P` or `Escape`.
- Start, resume, or restart with `Space` while the playfield is focused.
